# Projet — conception d'une base de données pour un cabinet de conseil

<!-- À COMPLÉTER : année, seul ou en groupe, SGBD utilisé si implémentation. -->

## Résumé

Projet du cours Info505 « Analyse des bases de données » : conception complète d'une
base de données relationnelle pour un cabinet de conseil qui place des candidats sur
des missions en entreprise. Rapport rédigé en LaTeX.
Code source : [dépôt ProjetBDCabinetConseil](https://github.com/thomaslahely/ProjetBDCabinetConseil).

## Modélisation : MCD et MPD

Le modèle conceptuel de données (MCD) décrit les entités candidat, entreprise, mission,
fonction, diplôme, institut, annonce et convention, ainsi que leurs relations. Le modèle
physique de données (MPD) le traduit en tables, colonnes et contraintes d'intégrité.

## Normalisation et dépendances fonctionnelles

L'étude des dépendances fonctionnelles entre attributs sert à normaliser les tables,
éviter les redondances et garantir l'intégrité des données.

## Technologies

Modélisation Merise (MCD, MPD), bases de données relationnelles, normalisation, LaTeX.
